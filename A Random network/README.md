# A Random Network

This folder contains the simulation and analysis code used to generate and analyze the results for the **random-network condition** presented in the paper.

The network is a directed Erdős–Rényi random network consisting of excitatory and inhibitory neurons. External input is modulated periodically at theta frequency, and the resulting network activity is analyzed in terms of burst dynamics, burst timing, theta phase, frequency content, and phase-amplitude coupling.

## Contents

```text
A Random network/
│
├── simulation.cpp
├── Analysis.ipynb
│
├── ActivityInTime.txt
├── EtaInTime.txt
└── Parameters.txt
```

### `simulation.cpp`

C++ code for generating the random neuronal network and simulating its dynamics.

The main parameters used in the simulations include:

* **Number of neurons:** `N = 2000`
* **Connection probability:** `p = 0.1`
* **Excitatory neuron fraction:** `E = 0.8`
* **Excitatory synaptic weight:** `W_E = +1`
* **Inhibitory synaptic weight:** `W_I = -4`
* **Excitatory synaptic lifetime:** `T_E = 5`
* **Inhibitory synaptic lifetime:** `T_I = 7`
* **Activation threshold:** `D = 8`
* **Theta period:** `T_theta = 200 ms`

The external activation probability is time-dependent and follows

$$
\eta_\theta(t)
=
\eta_0
+
\eta_A
\sin(\phi_\theta(t)),
$$

where the theta phase advances periodically with period `T_theta`.

The simulation records the network activity and the corresponding external input over time.

### `Analysis.ipynb`

Jupyter Notebook for analyzing the simulation output and generating the corresponding plots.

The analysis includes:

* detection of network bursts from the activity time series;
* estimation of burst duration;
* identification of the first burst in each theta cycle;
* calculation of the theta phase at burst onset;
* circular statistics of burst-onset phases;
* calculation of the power spectrum;
* extraction of low- and high-frequency components;
* phase-amplitude coupling (PAC) analysis;
* visualization of the temporal relationship between theta modulation and network bursts.

The notebook is intended to be run after the simulation output files have been generated.

## Simulation output files

Example output files are included in this folder so that the analysis notebook can be run **without first executing the C++ simulation**.

### `ActivityInTime.txt`

Contains the network activity as a function of time.

The file has two columns:

```text
time    rho
```

where `rho` is the fraction of active neurons at each simulation time step.

### `EtaInTime.txt`

Contains the external activation probability used at each time step.

The file has two columns:

```text
time    eta_theta
```

### `Parameters.txt`

Contains the model parameters used to generate the corresponding simulation output.

The parameters are stored in the following order:

```text
W_E
W_I
T_E
T_I
D
eta_0
eta_A
T_theta
```

The analysis notebook reads these values directly from `Parameters.txt`, so the analysis is linked to the parameters of the supplied simulation output.

## Reproducing the analysis

### 1. Compile and run the simulation

Compile `simulation.cpp` using a C++ compiler supporting C++11 or later. For example:

```bash
g++ -O3 -std=c++11 simulation.cpp -o simulation
```

Then run:

```bash
./simulation
```

The simulation generates:

```text
ActivityInTime.txt
EtaInTime.txt
Parameters.txt
```

in the working directory.

> **Note:** The simulation uses stochastic external activation and network generation. Therefore, independently generated realizations will not necessarily produce exactly the same time series as the example files included in this repository.

### 2. Run the analysis notebook

Open `Analysis.ipynb` in Jupyter Notebook or JupyterLab and run the cells sequentially.

The notebook expects the three text files generated by `simulation.cpp` to be located in the same directory as the notebook.

Alternatively, the included example output files can be used directly to reproduce the analysis and figures without running the simulation.

## Relation to the paper

This folder corresponds specifically to the **random-network control/condition** used in the paper. The corresponding `modular_network` folder contains the code and example data for the modular-network condition.

For the definitions of the model, simulation parameters, burst-detection procedure, and analysis measures, please refer to the corresponding sections of the paper.
